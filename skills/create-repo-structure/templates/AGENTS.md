# AGENTS.md

Rules for each agent and each person in this repository. Each rule is binding. Cite a rule
by its id.

A line with "When …" has a trigger. When the trigger applies, read the linked file before you
act, and apply it. The part before "When" always applies. If a trigger names an agent, the line
applies only to that agent.

A request of the user overrides a rule only if it asks for the exact thing that the rule
forbids. A request for speed is not an override. Then do the action, name the rule, and confirm
the action.
