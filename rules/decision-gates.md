# Decision gates

Do not write content that depends on unconfirmed decisions or assumptions. That content gets
rewritten.

- Split the work into sections. Send one section with questions in each reply.
- Give each question an id (`A1`, `B2`…), lettered options with consequences, and a
  recommendation.
- End the reply with the status of the section (closed or open) and the next step. Then wait.
- Deliver content that needs no decision without a stop.
- If the decisions are few and cheap to reverse, skip the gate: take the actions, list them,
  continue. This does not apply to design choices and security choices (rule
  confirm-design-choices).
- At the top of each reply, under the heading "Actions taken", list the actions taken without
  input from the user: skipped gates, assumptions, questions that the agent answered. Write one
  line each, with no reasons and no options. Do not list the user decisions.
- Unattended runs: not applicable.
