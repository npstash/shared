# Repo structure template

The skill [create-repo-structure](../skills/create-repo-structure/SKILL.md) holds a template of
the repository structure.

When you change one of these, ask the user if the skill and its templates must change too:

- the repository structure or the repo-structure rule;
- a root file that has a template in the skill, e.g. `AGENTS.md`, `.gitignore`, `.kilo/kilo.jsonc`;
- a file that the skill copies, e.g. `setup.sh`, `tests.yml`.
